Split the world into tiles, refresh nightly from the FIRMS API, and replace near-real-time weeks when standard data arrives.

SPEAKER 5 (about 35 seconds). The engineering choice is simple. The history changes slowly and is read far more often than it is written, so it does not need a server. Python turns 750 megabytes of NASA files into a 4.8 megabyte file in under a minute. The browser then calculates any area on the device, so you can draw any rectangle on the map. It is cheap to host and survives a traffic spike. We checked that the browser’s result matches an independent calculation exactly. The map draws no national boundary, because the data does not need one and boundaries are sensitive. This release covers India. Going global is designed but not yet built, so please treat that part as a plan.
